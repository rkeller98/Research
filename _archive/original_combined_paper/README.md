# Original combined geometry baseline

Moved unchanged from `legacy/original_combined_paper/` on 8 October 2026.
The original TeX, PDF and five PDF figures remain together so local figure
references still resolve. Original attribution and derivations are preserved.

The [migration matrix](../../docs/migration_matrix.md) assigns quadratic forms,
conic classification, PSM operating regions, EESM rank/nullspace, loss whitening,
voltage-only unboundedness and numerical-domain limitations to the active
PSM/EESM publications. This is retained once for provenance: the historical
renderings and exact source are not byte-identical active duplicates, and no
figure-generation recipe accompanies them. The locally ignored ZIP contains
the same seven scientific files plus TeX intermediates and remains outside
the versioned payload.

[The cleanup manifest](../../docs/final_cleanup_manifest.json) binds every
relocated versioned source to its pre-cleanup hash.
