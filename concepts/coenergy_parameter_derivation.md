# Magnetic co-energy for parameter derivation

## Status
Research concept, deliberately **not promoted to a paper yet**.

## Core idea
If a flux map is represented by a sufficiently smooth magnetic co-energy,

\[
\boldsymbol\psi = \nabla_{\mathbf i} W',\qquad
L_{\mathrm{diff}}=\nabla^2_{\mathbf i}W',
\]

then differential parameters follow from one common latent object rather than from independent differentiation of two noisy flux surfaces. Reciprocity is structural because the Hessian is symmetric. Eigenvalues and eigenvectors of the Hessian provide local principal incremental directions.

## Why it is separate
This is not the same research question as co-energy reconstruction. Reconstruction asks how to obtain an admissible field. Parameter derivation asks which machine parameters and local geometric quantities can be extracted from that field, with what uncertainty and physical interpretation.

## Missing before paper status
- a precise parameter set beyond the already-derived differential-inductance matrix;
- uncertainty propagation from flux/potential fit to the derived parameters;
- synthetic ground truth showing derivative/parameter advantage over independent map differentiation;
- at least one experimental or high-fidelity reference case;
- a clear statement of which quantities are coordinate-dependent and which are physically invariant.

The existing differential-inductance section in the co-energy papers is background for this future paper, not evidence that this separate contribution is already complete.
