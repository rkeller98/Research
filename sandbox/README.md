# Sandbox

Freier persönlicher Experimentier- und Lernbereich. Neue Untersuchungen beginnen
hier eigenständig, ohne Starterlösung oder vorgeschriebenes Framework.

Dauerhaft benötigte wissenschaftliche Module gehören nach `shared/python/`,
ausführbare Werkzeuge nach `scripts/`, kanonische Daten nach `datasets/` und
publikationsbezogene Experimente zum jeweiligen Paper. Erforderliche historische
Quellen liegen unter `_archive/`. Die bisherigen Dateien sind im
[Cleanup-Audit](../docs/final_cleanup.md) zugeordnet.
